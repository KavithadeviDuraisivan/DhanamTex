Supabase configuration

Credentials are hardcoded in index.html so all devices connect automatically.

1. Open index.html in any text editor
2. Find near the top of the <script> block:
  const SUPABASE_URL = '...'
  const SUPABASE_KEY = '...'
3. Replace with your Supabase Project URL and anon key
4. Save and re-upload to GitHub / Netlify
